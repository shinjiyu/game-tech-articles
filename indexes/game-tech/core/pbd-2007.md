# Position Based Dynamics（PBD）

- 出处：Müller et al., 2006 VRIPHYS / 2007 JVCIR  
- Tier: A · Indexed: 2026-09-30

## 主张

在位置层直接投影约束，避免显式力积分的过冲；用迭代满足距离/弯曲等约束，再反推速度。

## 为何重要

把 Jakobsen 游戏做法一般化，成为实时布料/软体/简单碰撞的默认范式。之后 XPBD、PBF 都站在这条线上。

## 局限

刚度与迭代次数、时间步耦合；不是严格能量/连续介质求解。

## 关键要点

- 未知量是位置修正，不是加速度。  
- 读代码时抓住：预测 → 投影循环 → 速度回写。
