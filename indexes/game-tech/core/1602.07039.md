# XPBD

- ArXiv: [1602.07039](http://arxiv.org/abs/1602.07039)  
- Tier: A · Indexed: 2026-09-30

## 主张

用合规（compliance）形式重写位置约束，使软硬更接近物理参数，减轻「多迭代就变硬」的老问题。

## 为何重要

生产引擎里说的「基于位置」，多数已是 XPBD 气质。从 PBD 往上补课，这一步仍在同一坐标系。

## 关键要点

- 调参时盯 soft compliance 与 Δt，而不是只加 iteration。  
- 仍解决不了「要工业级接触保证」——那是 IPC 的事。
