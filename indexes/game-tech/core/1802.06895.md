# MLS-MPM

- ArXiv: [1802.06895](http://arxiv.org/abs/1802.06895)  
- Tier: A · Indexed: 2026-09-30

## 主张

用 Moving Least Squares 传递简化 MPM 的力/动量交换，提升效率与实现友好度，并支持断裂与刚体双向耦合等扩展。

## 为何重要

MPM 系（含 Frozen 雪）之后，MLS-MPM 成为大量实时/研究实现的默认变体；浏览器 WebGPU 流体实践也常站在这条线上。

## 关键要点

- 适合水/沙/雪/泥跨材料；邻域搜索压力通常低于朴素 SPH。  
- 与 PBD 不是替代关系：一个偏连续介质粒子法，一个偏网格约束投影。
