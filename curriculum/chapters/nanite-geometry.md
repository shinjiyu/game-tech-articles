# Nanite 与几何线

UE5 发布时常与 Lumen 并列的是 **Nanite**：虚拟化微多边形几何。

## 脉络位置

手工 LOD / 减面 / 实例化硬扛三角面 → **按屏幕误差流式加载 cluster、软件光栅** → 接近电影级面数进实时。

## 和光照、物理的关系

| 技术 | 管什么 |
|------|--------|
| Nanite | 几何细节够不够画 |
| Lumen | 光够不够真、够不够动态 |
| Chaos / XPBD 等 | 物体怎么动 |

三者叠罗汉，不互相取代。

## 关键要点

- 谈「游戏画面跃迁」时，把几何线与光照线分开记。  
- 相关论文标签：`nanite` / `geometry` / `lod` / `visibility`。
