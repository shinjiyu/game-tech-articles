# 光照时间脉络（球谐之后）

你停在 **球谐（SH）/ PRT（约 2002）**：用低阶基函数扛**低频**间接光，角色可在有遮蔽的 GI 下动。

## 时间线

| 年代 | 节点 | 在干什么 |
|------|------|----------|
| 1975–1986 | 局部光 | Phong；Whitted / 路径追踪定数学（离线） |
| 1996–2001 | 烘焙 | Lightmap、环境贴图 |
| 2001–2005 | **SH / PRT** | 低频动态 GI（你在这附近） |
| 2005–2012 | Deferred + 屏幕空间 | 多灯；SSAO、SSR；探针 |
| 2011–2016 | 体素 + **PBR** | VXGI 等；金属度/粗糙度统一材质 |
| 2018–2021 | 硬件 RT | DXR/RTX；DDGI 等 |
| 2021–今 | **Lumen** 等 | 可动态生产级 GI；路径级实时仍在推进 |

## SH 之后缺什么、怎么补

- **缺**：高频——清晰镜面、硬阴影、小灯细节；大改场景常要重烤 PRT。  
- **补三条线**：屏幕空间（便宜假）· 世界空间缓存（探针/体素/Lumen）· 光线追踪（正确贵）。

## 同一帧分层（调试用）

1. 直接光 + 阴影  
2. 间接漫反射（GI）  
3. 间接高光 / 反射  
4. 材质响应（PBR）

## 关键要点

- 球谐不是终点，是「低阶基函数扛间接光」那一代的代表。  
- Lumen ≈ 光照侧后来的生产级动态跃迁（挂在渲染线，不是物理线）。
