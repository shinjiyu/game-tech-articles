# 实时有限元在 ACG 的进展

## 你的旧判断

「算力涨了，是不是可以实时有限元？」——**方向对，形态不是工业 FEA 原样进游戏**。

## 实际发生了什么

- CG 软体/布料学术里早有 FEM，但贵。  
- 近十年：隐式 FEM + **IPC 势垒接触** + GPU / 子空间 / 降阶，使中等规模四面体可交互。  
- 引擎「软体」常见 **共旋线性 FEM / 降阶 FEM**，不是完整非线性工业套件。

## 分工

| 目标 | 常见选择 |
|------|----------|
| 布料附件、绳子、手感 | XPBD |
| 大变形、堆不穿、抓取仿真 | FEM + IPC |
| 水/沙/雪/泥跨材料 | MPM |

## 关键要点

- 实时「够看的 FEM」更可行了；实时「认证级 FEA」仍不现实。  
- PBD 没死，有限元也没等算力自己变实时——算法与 GPU 一起把轻量 FEM 推进了 ACG。
