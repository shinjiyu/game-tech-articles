# 动画 / 网络 / 开世界等

物理与光照之外（音频另说），还有这些主干：

| 分支 | 在干什么 | 近年变化感 |
|------|----------|------------|
| 渲染其它 | 材质、后处理、TAA、粒子、GPU-driven | 持续快 |
| 动画 | 骨骼、IK、Motion Matching、学习型动画 | 较快 |
| 玩法 AI / 寻路 | Behavior Tree、NavMesh、感知 | 中等 |
| 网络同步 | 状态同步、Rollback、兴趣管理 | 较快（多人） |
| 开世界流式 | World Partition、HLOD、流式 IO | 较快 |
| 引擎架构 | Job System、ECS、内存 | 稳而重 |
| 内容管线 | 编辑器、烘焙、CI | 工业权重极大 |
| UI / 输入 / 相机 | 产品层 | 计算简单、产品重 |

## 和前两线对照

| 已梳理 | 同级其它 |
|--------|----------|
| 物理怎么动 | 动画怎么演、AI 怎么决策、网络怎么一致 |
| 光照怎么亮 | 几何怎么画、特效/后处理、世界怎么流进来 |

## 关键要点

- 「游戏技术」不是只有物理+光照；但论文感最强的仍常在渲染/物理/动画/网络。  
- 本库监控关键词偏图形物理与渲染；其它支柱可后续扩 `monitor.json`。
